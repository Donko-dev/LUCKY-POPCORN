🔒 Accès producteur

Entrez le code producteur pour gérer vos produits, services, activités, textes et réglages. Ce code est stocké uniquement sur cet appareil (aucun serveur, aucune base de données).

🚀 Publier vos changements pour TOUS vos clients

Ce que vous modifiez ici n'est visible que sur cet appareil, tant que vous ne l'avez pas publié. Pour que vos clients voient automatiquement vos changements sur leur téléphone :

  1. Faites vos modifications ci-dessous (produits, prix, textes...).
  2. Cliquez sur "⬇️ Télécharger catalog-data.json" et/ou "⬇️ Télécharger site-settings.json".
  3. Allez sur votre dépôt GitHub → glissez ce(s) fichier(s) à la racine (même nom, ça remplace l'ancien) → Commit changes.
  4. C'est tout : tous vos clients verront la mise à jour dès leur prochaine ouverture de l'app.

Modifiez le contenu, mettez en gras, italique, souligné, changez la couleur ou la taille de chaque texte affiché sur le site, sans toucher au code.

🛡️ Sécurité

Active un blocage du clic-droit, de la sélection et du copier-coller du texte sur le site, pour décourager la copie rapide de votre contenu.
Important à savoir : comme ce site est 100% autonome (sans serveur), aucune protection ne peut être totalement infranchissable — un visiteur technique averti pourra toujours contourner ce blocage via les outils du navigateur. C'est un frein, pas un coffre-fort.
